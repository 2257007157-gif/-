# 自动化视频工作流智能体

当用户希望自动生成、检查或交付 ComfyUI Seedance 2.0 R2V 视频工作流时，使用本技能作为自动化智能体入口。

## 智能体目标

- 收集并校验 4 张参考图：`sd_outfit_1.png`、`sd_outfit_2.png`、`sd_outfit_3.png`、`selfie_cartoon_style.png`。
- 生成适合 ByteDance2ReferenceNode 的中文提示词，保持第一人称自拍走秀视角。
- 给出可执行的 ComfyUI 准备步骤，帮助用户把素材放入 `ComfyUI/input` 并启动工作流。
- 在缺少素材或参数时，先输出缺失清单，再给出下一步操作建议。

## 默认执行流程

1. 读取用户需求，确认视频主题、服装风格、画幅比例、时长和转场偏好。
2. 检查参考图文件是否齐全；如缺少文件，列出需要补齐的文件名。
3. 生成最终 prompt，包含：第一人称自拍视角、三套服装依次展示、时尚走秀、故障转场、稳定人物身份。
4. 输出 ComfyUI 操作清单：复制图片、加载工作流、确认节点、运行生成、检查输出视频。
5. 交付结果摘要，说明输入、使用的 prompt、输出位置和后续可优化项。

## 默认 Prompt 模板

```text
第一人称自拍视角的时尚走秀短视频，人物身份和脸部特征始终保持一致。视频依次展示三套服装：第一套参考 sd_outfit_1.png，第二套参考 sd_outfit_2.png，第三套参考 sd_outfit_3.png；人物自拍形象参考 selfie_cartoon_style.png。镜头自然前进，姿态自信，背景为高级时装秀氛围。每套服装之间使用短暂 glitch 故障转场，画面清晰、节奏流畅、服装细节突出、无多余人物、无明显变形。
```

## 质量检查标准

- 参考图命名与工作流节点一致。
- 三套服装都被展示，且顺序正确。
- 人物脸部、发型和整体身份保持一致。
- 转场不遮挡服装关键细节。
- 输出视频可播放，且保存路径已记录。
