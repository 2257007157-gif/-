## 判定与防误报
- 当前 `LIVE` 需要两个独立网页的相互印证：公开主页上账号名称、抖音号及指定直播间的「直播中」入口；直播间网页上精确匹配的账号标题与描述。
- 账号及房间 ID 均不允许重复，四个监控目标由用户确认。
- 若有页面网络异常、访问受限、验证码、账号身份不匹配，或没有直播中入口，脚本一律保留 `UNKNOWN`，**不得自动写成 `OFFLINE`**。
- `LIVE` 表示检测快照，不能代表整场连续直播或历史直播时长。
